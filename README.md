# 🌐 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built to showcase my skills, projects, and development journey.

This portfolio features a clean and visually appealing design, smooth animations, interactive 3D elements, and responsive layouts to provide an engaging user experience across different devices.

## Live Demo

🔗 **Live Website:** https://my-portfolio-ten-eta-28.vercel.app/

## Features

- Modern and clean user interface
- Fully responsive design
- Interactive 3D elements
- Smooth animations and transitions
- Showcases personal skills and projects
- Engaging user experience

## Tech Stack

- **React.js** – Building reusable UI components
- **Next.js** – React framework for web development
- **JavaScript** – Core programming language
- **Tailwind CSS** – Styling and responsive layouts
- **Three.js** – Creating interactive 3D visuals
- **Framer Motion** – Smooth animations and transitions
- **Lucide React** – Modern icons

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/rifaa-tamanna/My-Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
